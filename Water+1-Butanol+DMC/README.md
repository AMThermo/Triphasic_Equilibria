# Vapor-Liquid-Liquid Equilibria for the Water + 1-Butanol + DMC Mixture.
This repository contains two Jupyter-Notebooks with the sgtpy code to model this ternary triphasic mixture via the SAFT-VR-Mie model for phases and coupled to the SGT for interfaces. The notebook also contains and plots the experimental VLLE, bulk densities and interfacial tensions measured at the Cohesion Laboratory (Concepción University). Note that you need to install the sgtpy module to use the notebook. We refer the reader to sgtpy documentation for information on how to install it: https://github.com/gustavochm/sgtpy. 

### Documents compiled in this repository:
  - *VLLE_SI.ipynb*: The Jupyter-Notebook with the isobaric (P = 101.3 kPa) three-phase line modelling with a non-isothermal ternary diagram (x-w-y) and a temperature 3D (T-x-w-y) projection.
  - *TENS_SI.ipynb*: The Jupyter-Notebook with the modelling of the T = [298 - 353]K three-phase bulk mass densities, interfacial tensions and interfacial density profiles.
